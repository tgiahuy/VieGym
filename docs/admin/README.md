# VieGym Web Admin

Toàn bộ UI implementation blueprint, đặc tả màn hình, chức năng, nghiệp vụ, API dự kiến và tiêu chí nghiệm thu của Web Admin được quản lý trong một tài liệu duy nhất:

- [VIEGYM_ADMIN_SPEC.md](./VIEGYM_ADMIN_SPEC.md)

Tài liệu này chốt design token, kích thước layout, component dùng chung, wireframe, responsive behavior, trạng thái tương tác và acceptance criteria để Frontend có thể triển khai trực tiếp. Đây là nguồn tham chiếu chính cho UI/UX, Frontend, Product, Backend và QA.
