# VieGym Frontend

Ứng dụng web VieGym được xây dựng bằng React, TypeScript và Vite.

## Tổng quan

VieGym là ứng dụng hỗ trợ tập gym, dinh dưỡng và cá nhân hóa bằng AI, được thiết kế dành cho người dùng Việt Nam.

## Bắt đầu

Từ thư mục `frontend/`:

1. Cài đặt dependencies:
   ```bash
   pnpm install
   ```
2. Chạy development server:
   ```bash
   pnpm dev
   ```
3. Kiểm tra trước khi commit:
   ```bash
   pnpm lint
   pnpm build
   ```
